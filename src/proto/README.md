# Catatan protocol WhatsApp

Folder ini disediakan sebagai tempat dokumentasi/update terkait protocol. Baileys mengelola implementasi protokol dan definisi/generated protobuf yang dipakai oleh library.

Jangan menambahkan file sesi, pairing code, kredensial, atau dump data pengguna di sini. Jangan menganggap file `.proto` placeholder sebagai implementasi yang kompatibel: definisi schema saja tidak cukup untuk membuat client "work all proto". Untuk pembaruan, ikuti perubahan upstream Baileys, gunakan file yang memang diperlukan dan berlisensi sesuai, lalu uji dengan versi library yang ditetapkan.
